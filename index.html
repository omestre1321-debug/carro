🏎️ Carrinho de Corrida Micro:bit

Este site hospeda a documentação e o painel de controle do seu carrinho controlado por rádio e sensor de inclinação.

Comandos do Controle:

  • Botão A: Vira para a ESQUERDA
  • Botão B: Vira para a DIREITA
  • Inclinar para Frente: Anda para FRENTE
  • Inclinar para Trás: Anda para TRAS
  • Sem botões/inclinação: Permanece PARADO
